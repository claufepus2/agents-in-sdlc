O [agente na nuvem do GitHub Copilot](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent) permite que o GitHub Copilot trabalhe de forma assíncrona na nuvem. Você atribui o trabalho no GitHub, e o agente na nuvem o executa em segundo plano — explorando o repositório, fazendo alterações e abrindo uma pull request — enquanto você fica livre para fazer outras coisas.

Ao longo destes exercícios, você vai adicionar instruções personalizadas que o agente na nuvem seguirá e, depois, atribuir uma issue do GitHub para que ele implemente o trabalho. Você vai revisar e usar agentes personalizados para orientar a abordagem, acompanhar e direcionar sessões no painel de agentes e, por fim, revisar as pull requests e iterar sobre os resultados.

## Pré-requisitos

Antes de participar deste workshop, verifique se você tem:

- [ ] Uma conta do GitHub com um plano ativo **Copilot Student, Pro, Pro+, Business ou Enterprise**
- [ ] O agente na nuvem do Copilot habilitado para sua conta ou organização

> [!TIP]
> Não tem um plano pago? Estudantes com status verificado podem obter o GitHub Copilot gratuitamente pelo [GitHub Education][callout-student-plan-education]. O plano **Copilot Student** inclui o agente, MCP, revisão de código e os recursos do Copilot CLI usados neste workshop — assim, você pode concluir todos os roteiros com ele.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> O agente na nuvem está disponível nos planos **Copilot Student, Pro, Pro+, Business e Enterprise** — em todos os planos, exceto Copilot Free. No Copilot Business ou Enterprise, um administrador precisa habilitá-lo para a organização.

> [!NOTE]
> Este roteiro não aborda MCP. Para aprender a usar servidores MCP com o Copilot, consulte o [roteiro do CLI](../cli/) ou o [roteiro do VS Code](../vscode/).
